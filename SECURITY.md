# Security Policy

## Supported versions

Security fixes are applied to the current `main` branch. Older commits, local
snapshots, and generated applications are not maintained release lines.

## Reporting a vulnerability

Do not include credentials, personal data, exploit details, or other sensitive
material in a public issue. Submit a private vulnerability report through the
repository's **Security** tab:

<https://github.com/buckeye7066/local-ai-factory/security/advisories/new>

If GitHub does not offer that private form to your account, contact the
repository owner through GitHub without vulnerability details and request a
private reporting channel.

Include the affected commit, component, reproduction conditions, impact, and
the smallest safe proof of concept. The maintainer will aim to acknowledge a
report within five business days, provide an initial triage decision within ten
business days, and coordinate disclosure after a fix is available. Timelines
may change for complex or third-party issues; material changes will be shared
with the reporter.

Never send live API keys or tokens. Revoke any credential that may have been
exposed before submitting the report.
